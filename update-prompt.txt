Bear-steepener bonus: add +0.04–0.06 ONLY when BOTH (UST_30Y > 5.0%) AND (30Y − 10Y > 1.0%).
Use the JGB 10Y and UST 30Y values confirmed in this same update. Round to 2 decimal places.

**USD/JPY** — Fed H.10 (federalreserve.gov/releases/h10). Daily rate for [INSERT LAST TRADING DAY]. 1 decimal.
**JGB 10Y (%)** — Bank of Japan (stat-search.boj.or.jp) or MOF Japan. 2 decimal. Confirm BEFORE computing RFI.
**UST 30Y / 10Y / 3Y (%)** — Fed H.15 (federalreserve.gov/releases/h15). 2 decimal.

### Group 2: Silver & Gold

  ARCC (38% weight) + FSK (25%) + OBDC (24%) + GBDC (13%)

Filing schedule: Q1 ~May 15 | Q2 ~Aug 15 | Q3 ~Nov 15 | Q4 ~Feb 15.
Between filings: carry forward the prior quarter's value UNCHANGED (no linear interpolation).

WARN > 2%. ALARM > 3%. Always mark ~.

!! DO NOT use Fitch all-inclusive rate (reports ~6% for 2025 — different, broader LME definition) !!
Three measures exist: (1) payment-only ~0.87% Aug 2026; (2) dual-track ~2.87% Aug 2026 ← USE THIS;
(3) Fitch all-inclusive ~6% ← DO NOT USE. WARN > 3%. ALARM > 5%. Always mark ~.

**HY distress ratio (% bonds >1000bps OAS)** — S&P HY Distressed Bond Index or LCD. WARN > 8%. ALARM > 12%.
**Avg leveraged loan bid (cents on $)** — PitchBook LCD / Morningstar LSTA index. WARN < 96¢. ALARM < 93¢. Round to 1 decimal.
**CLO equity trailing 12M return (%)** — Palmer Square / Intex CLO data. WARN < 5%. ALARM < 0%. Always mark ~. Round to nearest integer.
**Lev-loan refinancing volumes ($bn, monthly)** — PitchBook LCD monthly issuance report (refi-only). WARN < $20bn. ALARM < $10bn. Mark ~.
**PIK toggle + amend-and-extend ($bn, monthly est.)**

No single authoritative public source — construct the estimate using this priority order:
  (1) Octus (octus.com) — "Distressed A&E / LME Volume" tables (paywalled; most comprehensive)
  (2) PitchBook LCD Default Monitor (pitchbook.com/lcd) — "LME Volume" section
  (3) SEC EDGAR BDC 10-Q filings — manual tally of PIK elections + maturity extension $ amounts
  (4) If none available: use the structured CONSTRUCT method in the inline comment.
DISTRESSED transactions only — exclude routine repricings done by healthy borrowers.
CONSTRUCT (fallback, when sources 1–3 unavailable):
  - Start from prior month's value
